Neural Physics Lab — материалы для команды

Посмотреть
Распакуй архив целиком и открой index.html в браузере на компьютере.
Выбери один из четырёх вариантов. В Notes лежат палитры, шрифты и описание анимации.

Добавить интерактивный вариант в Next.js
1. Создай в вашем проекте папку public/neural-studies/.
2. Скопируй туда index.html, все файлы JS и CSS, lab-qr.png и папку fonts/ из этого архива.
3. Запусти проект обычной командой вашей команды. Открой /neural-studies/index.html в браузере.
4. Добавь ссылку на выбранный экран. Например, /neural-studies/index.html#folio/lab открывает лабораторию Field Notes.

Для встраивания в JSX
<iframe
  title="Neural Physics Lab — Field Notes"
  src="/neural-studies/index.html#folio/landing"
  style={{ width: '100%', height: '100dvh', border: 0 }}
/>

Перенести оформление в существующие страницы
В app.js находятся разметка экранов и настройки направлений, в style.css — цвета, сетка и адаптивная вёрстка. В art.js — отрисовка маятника на canvas. simulation.js обучает компактные демонстрационные модели. Для интеграции с вашим действующим /lab подключите элементы управления и метрики к вашему TypeScript-движку. Экспериментальные числа взяты из исходного проекта.

Добавить в прототип Figma
В screens/ выбери папку понравившегося направления. Перетащи PNG на холст. Каждый PNG импортируется как одно изображение. Чтобы сделать кликабельный сценарий, создай фрейм для каждого экрана, помести поверх CTA область нажатия и свяжи её со следующим фреймом во вкладке Prototype.
